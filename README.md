# Turing-machine-app

チューリングマシンの動きを1ステップずつ観察できるシミュレータです。進数変換のプログラムをプリセットとして収録しています。

## プリセット
- 10進 → 2進 / 2進 → 10進
- 2進 → 1進 / 1進 → 2進
- 2進数 +1

遷移表はアプリ上で編集でき、独自のプログラムも実行できます。

```
start: q0
halt: done
// 状態, 読む -> 書く, L|R|S, 次の状態   (_ は空白)
q0, 1 -> 0, R, q1
```

## 開発
```sh
npm install
npm run dev     # http://localhost:5173
npm test
```
